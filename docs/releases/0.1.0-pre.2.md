# 0.1.0-pre.2 release scope

Experimental Windows prerelease for use with owner-supplied PC game data. This
remains a compatibility/modernization project, not a completed recompilation.

## Changes since pre.1

- Correct interpolation-boundary rewinds and initialize the first saved history
  bank before rendering. Live traces verify stable original camera framing and
  approximately 50 simulation steps/s independently of rendering.
- Correct signed-RHW, color-only and far-depth-crossing background cases, with
  GPU coverage and graphics-state restoration checks.
- Correct the identified stencil-shadow composite being restricted to the old
  4:3 center. Production-bridge GPU tests cover full-width and outermost pixels,
  while an ordinary HUD control remains centered.
- Add native F1 settings, controller Start + View/Select, Xbox hints, automatic
  menu/match layouts and configurable raw joystick button mapping.
- Add original, experimental wide and distant camera presets. Presets also work
  without Hor+, while the default non-Hor+ camera path remains unchanged.
- Select Soccer Mania or Football Mania regional resources independently of text
  language. Preserve the verified original simulation clock.
- Add generated title sidebars matched privately to the original edge colors;
  keep the original title artwork and logos unchanged.
- Extend private imports with recognized disc-sector layouts, executable-donor
  repair and reuse of owner-supplied graphics backends.
- Validate import/profile preparation with all three owner sources and preserve
  their original files. Recover failed staging with copied read-only files.
- Correct a reproduced layered COM Release recursion on second-device creation.

## Packages

The source ZIP contains committed project code and permitted dependencies only.
Its embedded inventory records the exact source commit and member hashes.

The Windows x64 portable ZIP includes the launcher, Python/Tk/Pillow/SDL runtime,
project graphics/input bridges for the original x86 game, and license notices.
Extract the whole folder into a writable location and run `OpenSoccerMania.exe`.
Keep all accompanying files. No system Python installation is required.

Neither package contains game executables, game media, extracted title images,
saves, private captures or dgVoodoo. The launcher requests the owner's files.

## Verification and limits

Final build checks and package hashes accompany the release assets. Automated
package smoke tests open all four launcher pages with temporary preferences and
validate the actual bundled resources. GPU tests cover focused reproduced cases;
they do not certify every map, camera or graphics driver.

| Control | Result |
| --- | --- |
| Python tests | 76 run, one skipped in local validation |
| Native focused checks | 14 passed, x86 LLVM-MinGW |
| Stencil resolve GPU regression | Passed with the production bridge, including outer pixels and a centered-HUD control |
| Portable launcher candidate | Four pages opened/closed; private settings and packaged resource hashes validated on an isolated desktop |
| Three owner source imports | Private import/profile/title decoding passed; EA required an explicit intact executable donor; protected source hashes unchanged; gameplay not tested in this check |
| Final ZIP extraction | Recorded with the final artifact hashes in release notes |

Still unverified: complete goal/replay camera sequences, every map's shadows and
effects, full-width random title wipes, complete matches/save-reload, physical
controllers, 4K hardware allocation and hardware VRR. The Xbox navigation legend
does not replace every original in-game button graphic. VRS/TAA/DLAA are not
implemented. Some isolated game shutdown states require terminating that test's
own process; clean shutdown is not universally established.

Requested render caps through 480 FPS/Unlimited and display refresh through
240 Hz do not establish locked 240-FPS gameplay. Known original logic is 50 Hz;
no verified 60-Hz region route has been found.
