# 0.1.0-pre.1 release scope

This prerelease documents the first experimental Windows source snapshot. It is intended for development and controlled testing with legally owned PC game data. It does not promise a finished port, universal disc compatibility or stable 240-FPS gameplay.

## Distribution

The Git tag identifies the exact source revision. GitHub provides source archives; no proprietary game executable, data, captures, saves or third-party graphics wrapper is included. MinHook is vendored at upstream revision `c3fcafdc10146beb5919319d0683e44e3c30d537`. SDL3's redistributable runtime and its license are included for the launcher controller layer. Build the project's x86 bridge DLLs locally using LLVM-MinGW and follow the README for dependencies.
