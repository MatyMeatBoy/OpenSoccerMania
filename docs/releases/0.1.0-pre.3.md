# 0.1.0-pre.3 — self-contained portable import

This prerelease fixes a packaging error in pre.2: a clean PC was asked to locate
`D3D8.dll` and `dgVoodoo.conf`, because development imports reused an existing
private backend instead of shipping it. The portable now needs only the owner's
valid game ISO or extracted/installed game folder.

- Include the official, unmodified dgVoodoo 2.87.6 x86 D3D8 component and default
  configuration for this dedicated game modification, with license notice and
  pinned hashes. Provision missing private graphics files automatically.
- Remove the graphics DLL/configuration selection dialogs. A damaged package
  reports that the whole portable ZIP must be extracted again.
- Preserve the original per-window message chain across graphics-device
  recreation. This corrects a reproduced startup recursion with the included
  backend; forwarding-layer and F11 regressions pass with new and old backends.
- Read supported ISO9660/Joliet images internally, including recognized raw-sector
  layouts. No installed 7-Zip, separate extractor or network download is needed.
- Extend the frozen-launcher smoke test to import an asset-free synthetic ISO
  into empty temporary preferences, provision graphics, and save the profile with
  OS mounting disabled and external process creation forbidden. It never starts
  the synthetic executable or the game.

The game and its media remain user-supplied. An ISO whose executable is missing,
zero-filled or corrupt cannot become a playable original through bundled runtime
dependencies; select an intact owned copy. Unknown/unsupported disc layouts fail
with an import error instead of requesting an external component.

Existing unknown DLLs and private configurations are preserved. The vendor
component in the pack stays byte-identical to the official download; only the
private game's configuration receives selected graphics settings.

Prior gameplay limits remain: full goal/replay and all-map coverage, physical
controllers, 4K/VRR hardware acceptance and sustained 240-FPS gameplay are not
established by this packaging fix. Verification and immutable artifact hashes
accompany the release.
