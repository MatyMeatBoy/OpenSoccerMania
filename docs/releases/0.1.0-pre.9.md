# 0.1.0-pre.9 — Reproduction and validation baseline

This baseline retains the portable Windows launcher, standard-user storage,
shared icons/favicon, four controller prompt families and existing graphics,
save and window corrections. Supply your own supported original PC game files.

## Changed

- The source owner-game probe now applies its `--fps` argument to the actual
  render limit. Previously `--fps 60` generated RenderFPS=0, leaving rendering
  uncapped. The unused ProbeFPS diagnostic is removed. Requested render caps
  are separate from measured FPS and the original logical clock.
- Probe cleanup records the exact owned window, client dimensions, minimized
  state and WM_CLOSE delivery on its private desktop. It waits for normal exit
  before stopping observation. Forced termination remains a failed close result.
- Replay/window follow-up now records observed window states, visible scenes,
  copied-save hashes and the limitations of Quick Start reproductions. See
  [replay evidence](../replay-transition-pre8.md).

## Recorded focused verification

An isolated owner-game control reproduces the ignored 60 cap before the change.
Corrected 60 and 120 controls verify matching generated INI and native startup
values, with configured logical frequency still 50 Hz. Both close with code 0
after successful WM_CLOSE delivery, with the input desktop unchanged. These
are configuration/lifecycle checks, not locked-FPS or long-session equivalence.

The previous same-profile window-cycle run verifies actual resize, minimization
and restoration, halftime/second half, a later visible replay and clean close.
It uses pre.8's exact bridge and does not prove the original intermittent black
replay is fixed. Package-specific verification accompanies this release.

The pre.9 source passes 149 Python tests (one Windows privilege skip), 22 named
native CPU checks and 31 GPU/input/import cases using the exact frozen bridge.
The frozen launcher passes all four pages, synthetic ISO import, graphics
provisioning and four controller-family previews. A real nonadministrator token
also starts it with NTFS installation writes denied, observes both icon sizes,
creates per-user storage and exits zero; the fixture ACL is restored afterward.

## Still in progress

Physical PS4/Switch/Deck and four-controller hardware, Linux/Proton Gaming Mode,
4K/VRR and exclusive device loss remain open. Full campaign/tournament/save
recovery, all-map shadow/replay coverage and long-session timing/audio equivalence
also remain unfinished. Playable synchronized online matches, VRS and temporal
AA are not implemented. Catalog submissions still need authenticated portal
access; prepared public cards are not submitted/accepted listings.
