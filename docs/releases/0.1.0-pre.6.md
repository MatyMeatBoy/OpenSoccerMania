# 0.1.0-pre.6 — Save-worker and window recovery

This Windows prerelease continues the standard-user baseline. The portable
launcher includes its dependencies, graphics backend and shared icons; supply
your own valid game files. Original game data is not distributed.

- Prevent an idle save worker from erasing a request queued after its command
  snapshot. Require matching worker signatures and preserve normal/invalid
  dispatch, save bytes and genuine error results.
- Preserve Win32 error state across save metadata normalization and optional
  isolated diagnostics.
- Recompute adaptive raster scales after device reset, including an unchanged
  client size. Discard the cached pre-reset logical projection.
- Preserve manually resized windows by scaling adaptive presentation into the
  existing client instead of letting the backend resize it to the source ROI.

## Verification

125 Python tests run successfully with one local privilege skip. Twenty-one
named native CPU checks and 27 GPU/input/import cases pass. The worker fixture
reproduces the old lost-request interleaving and checks next-pass execution,
register/stack preservation, dispatch boundaries and unsupported-code exclusion.
Reset checks include invalid-call recovery, pixel readback and retained shaders.

The rebuilt frozen launcher passes its four-page/import/graphics smoke. A normal
startup under a nonadministrator token and real install-directory write denial
uses the user-data fallback, retains its window icons and closes cleanly.

Three fresh owner-game profile loads read their complete payload, preserve save
hashes and close cleanly. A real Story run advances from City Park to Western
Junction, changes only its selected save bank and preserves that checkpoint in a
new process. Real menu/settings window resizing retains the requested dimensions.
These are selected acceptance cases, not complete campaign or hardware coverage.
