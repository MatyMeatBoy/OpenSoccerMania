# 0.1.0-pre.4 — independent controllers and recoverable import

This Windows prerelease fixes private read-only executable replacement and recovery after an interrupted pre.3 import. Retry a valid owned game without administrator elevation or deleting the library. Foreign or corrupt executables remain rejected.

- Four separate native DirectInput gamepads fed by bundled SDL; gameplay no longer emulates the keyboard player. Stick and D-pad share movement. Keyboard remains independent.
- Xbox positions follow PS2 gameplay: A pass, B shoot, X long ball, Y power-up, LB sprint, RB switch. Menu A confirms and B returns.
- Select / View skips videos on release. Start pauses. Start + Select opens settings and consumes both standalone actions. A movie-only native gate prevents a pending skip from backing out of the following menu.
- Hide the pointer after controller activity, restoring it on real mouse movement. Hiding is restricted to the focused game client.
- Remove Smooth Mode and the permanent controller legend. Keep first-snapshot camera initialization independently.
- Widescreen defaults on. Original-ratio mode explicitly maps presentation rectangles and fits 4:3 within the output.
- Extend the native blue menu/loading grid using original loaded tiles. Replace original numeric footer icons with A/B in their existing locations when a controller is connected.
