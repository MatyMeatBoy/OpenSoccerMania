# 0.1.0-pre.5 — Standard-user baseline and native stability

This Windows prerelease establishes the next tested baseline while modernization continues. It includes the portable launcher and source package; supply your own valid game folder or supported disc image. No original game data or extracted game artwork is distributed.

- Run without administrator permission. Writable portable installations keep their local data; protected installations use `%LOCALAPPDATA%\OpenSoccerMania`. The game uses its private profile and virtual legacy registry keys, including the API variants actually imported by the supported executable.
- Share original football/brick icons across launcher and game windows, the executable and packaged SVG/ICO/PNG favicons.
- Preserve logical backbuffer and viewport identity after device reset. Map rectangle clears, including depth and stencil, to the physical render target while retaining render-texture coordinates.
- Keep animated menu players visible and aligned with their selection cells. Preserve their local projection and restore viewports after each draw; gameplay cameras and optional distant zooms remain independent.
- Guard save-list metadata parsing against null, blank, unterminated and unreadable records. Preserve valid metadata and all save files.
- Correct gameplay/pause context detection for controller mapping. Keep private diagnostic input exclusive while preserving normal physical input.
- Provide a repeatable native GPU suite and a corrected private-desktop test harness. RGB565 backbuffer captures now produce diagnostic images instead of reporting success without a file.

## Verification

124 Python tests run successfully with one existing Windows symlink-permission skip. Twenty-one named native CPU checks and seventeen GPU/input/import cases pass, including production-DLL save guards, clear rectangles, render-state restoration, layered window/COM ownership and repeated reset. The frozen launcher smoke checks four pages, synthetic ISO import and bundled graphics provisioning.

Private owner-game tests verify nonadministrator startup, protected-install data fallback, 3840x2160 target allocation, a completed Quick Start match with goal/replay/halftime/final statistics, profile reload, menu-player alignment, gameplay/pause/resume context, and bounded clean shutdown in those runs. These are separate acceptance cases, not universal hardware or all-map certification.

## Still in progress

- Persistent Story/tournament progression and broader save recovery.
- An earlier nearly black replay exit: a later complete match did not reproduce it; its cause and universal correction remain unproven.
- All-map camera, net/shadow/effect and resize/movie-transition acceptance.
- Physical four-controller matches, wireless/vendor hardware, live 4K/VRR presentation and sustained locked 240 FPS.
- Playable online integration: the included four-seat room/input relay remains a foundation, not a synchronized online game. VRS and temporal AA are not implemented.

The test-desktop harness previously relied on a CPython STARTUPINFO attribute that was ignored. It now uses native CreateProcessW and verifies the actual private desktop. Historical background-only probes must not be interpreted as proof of desktop isolation; the release evidence above distinguishes repeated cases and their limits.
