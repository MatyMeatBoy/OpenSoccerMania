## Recorded acceptance

The final source passes 148 Python tests (one Windows privilege skip), 22 named
native CPU checks and 31 GPU/input/import cases on the exact frozen bridge.

All four launcher previews and Auto/manual persistence were exercised on a
private desktop. The owner game completed 16 F1/menu commands, displayed all four
manual families, persisted style changes and exited cleanly. GPU checks upload
all 16 face images and compare four distinct rendered footer glyphs. These tests
use diagnostic input; physical devices are not inferred from them.

The frozen launcher passes resource, four-page, synthetic-ISO import, graphics
provisioning and four-family preview smoke. With a real standard-user token and
NTFS install writes denied, it starts, retains both window icon sizes, selects
writable per-user storage and closes cleanly. Test ACLs are restored.

Final source/archive verification and checksums accompany the published release.
